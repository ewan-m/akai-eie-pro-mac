What this is

A native CoreAudio driver for the Akai EIE Pro on modern macOS. No kernel extensions, no Rosetta, no workarounds. Install it, plug in the interface, it shows up in your DAW. That's it.

4 in, 4 out, 24-bit, 48kHz. Adjustable buffer size so you can dial in your latency in FL Studio, Ableton, Logic, whatever you use. Built from the ground up using the same USB protocol knowledge as the working Linux driver.

Works with everything that uses CoreAudio

Logic Pro, Ableton Live, FL Studio, Reaper, Audacity, GarageBand, OBS, Zoom, Discord, Google Meet — if it has an audio device dropdown on macOS, the EIE Pro will be in it.

Install

1.

Download the .pkg and run it. It drops the driver into /Library/Audio/Plug-Ins/HAL

2.

Restart CoreAudio, or just reboot.
sudo launchctl kickstart -kp system/com.apple.audio.coreaudiod

3.

Plug in the EIE Pro. It appears as "AKAI EIE Pro" in Audio MIDI Setup and any app.

Requires macOS 13 Ventura or later. Works on M1, M2, M3, M4, and Intel Macs. The EIE Pro connects over USB 2.0 — any port works, including via hubs and dongles.
